# Apka Fiszki

Pierwsza wersja aplikacji iOS w SwiftUI.

Funkcje:
- karta z hiszpańskim słowem i zdaniem,
- obrót karty po dotknięciu,
- polskie tłumaczenie na odwrocie,
- odsłuch hiszpańskiego słowa,
- poprzednie/następne słowo,
- przykładowy zestaw słówek zapisany lokalnie.

Projekt nie wymaga internetu podczas działania aplikacji.
